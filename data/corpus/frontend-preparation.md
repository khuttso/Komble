# Prepare for a junior frontend interview

Practise explaining the roles of HTML, CSS and JavaScript. HTML describes
document structure, CSS controls presentation, and JavaScript adds behaviour.
Use a small project example to explain how the parts worked together.

Prepare to discuss accessible form labels, keyboard focus and readable validation
messages. For a layout problem, describe how you reproduce it, inspect the page,
check responsive styles and verify a change. Discuss what you actually built and
what you still need to learn. A job advert can help you identify relevant topics,
but it does not reveal the employer's exact private interview questions.
